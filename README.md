# PRODIGY_GenAI_02

## Task 02: Image Generation with Pre-trained Models

### Objective
Generate images from text prompts using a pre-trained generative AI model.

### Description
This project uses a pre-trained Stable Diffusion model to generate an image from a text prompt.

### Technologies Used
- Python
- Stable Diffusion
- Diffusers
- PyTorch
- Transformers

### Prompt Used
A futuristic city with flying cars at sunset, cinematic digital art.
